About Zishu Deep AI

Welcome to the Future of AI: Zishu Deep AI v5.0.0!

We are thrilled to announce the biggest update in our history. We have completely ripped out the old WebView architecture (v4.0) and rebuilt the entire app from the ground up using Native Java. This means you get buttery-smooth performance, zero lag, and a true Android experience.

Here is everything packed into v5.0.0:

✨ The All-New Native Experience: No more loading screens or lag. The app is fully native, making scrolling, typing, and streaming incredibly fast.

💻 Advanced Code Workspace: Zishu Deep AI is now a coding beast. When the AI writes HTML/CSS/JS, you get a built-in Workspace with:

· Live Preview: Run and test web code instantly.
· Code Editor: Edit the generated code right inside the app.
· Console Logs: Debug your code with the built-in web console.
· Download & Copy: Save your files directly to your phone's Downloads folder with one tap.

🔑 Bring Your Own Key (BYOK): Complete control over your AI. Connect with OpenAI, Groq, OpenRouter, Google Gemini, Anthropic, and more. Auto-detects the best free models for you.

🎨 AI Image Generation: Switch to Image mode and generate stunning visuals right from the chat.

🎤 Native Voice & TTS: Seamless voice-to-text input (with append mode for long prompts) and a highly natural text-to-speech engine that reads AI replies back to you.

📁 Smart Attachments: Attach text files and images. View them in beautiful cards, and preview the full code/images with a dedicated full-screen viewer.

🌗 System-Wide Theming: Beautifully crafted Dark, Light, and System themes that change instantly without restarting the app.

🔒 100% Private: All your chats, API keys, and files are stored locally on your device using an encrypted SQLite database. We don't have servers; your data is yours.

🛠️ Pro Features:

· Pin, Rename, and Delete chat histories.
· Custom SVGs for a premium UI.
· Auto-save responses so you never lose an AI reply, even if the app closes.
· Markdown and Syntax Highlighting for code.

Upgrade your AI journey today. Download Zishu Deep AI v5.0.0 and build, chat, and create like never before!
