About Zishu IDE

> Zishu IDE lets you create, edit, build and install Android apps entirely on your phone. No computer, no Android Studio and no cloud account are needed.
>
> WHAT YOU CAN DO
> • Start a project from a template (Java, Kotlin, XML layouts, programmatic UI or a WebView app)
> • Write code in an editor with syntax highlighting, tabs, undo/redo, find and replace, a file explorer and a problems list
> • Build a real APK on the phone itself and install it with one tap
> • Use AndroidX and other libraries from Google Maven and Maven Central
> • Write Kotlin (compiler version 1.9.24) and Java (levels 5 to 15, default 15)
> • Import a ZIP file or clone a GitHub repository, and the project is laid out for you
> • Sign your APK with your own keystore
> • Use Zishu Terminal, a built-in terminal with IDE commands and an Android shell
> • Keep your projects and built APKs in a visible ZishuIDE folder, so you can reach them from any file manager
>
> HOW IT WORKS
> The build runs on your phone with aapt2, a Java compiler, the Kotlin compiler and D8. On first launch the app offers to download the libraries and the Kotlin compiler it needs for builds. After that, builds work from the stored files. An optional cloud build through your own private GitHub repository is also available.
>
> PRIVACY
> Your projects stay on your phone. Your debug signing key is generated on your device. Signing passwords are never saved. A GitHub token, if you choose to use the cloud build, is stored encrypted on your device and sent only to GitHub.
>
> GOOD TO KNOW
> • Needs Android 8.0 or newer and a 64-bit ARM phone
> • Internet is needed once to download libraries and the Kotlin compiler
> • Building on the phone does not support Jetpack Compose, annotation processors (kapt, ksp, Room, Dagger or Hilt compilers), multi-module Gradle projects or native NDK code
> • Apps built on the phone are debug-signed with a key unique to your install
>
> Zishu IDE is made for learners, hobbyists and developers who want to build Android apps anywhere, even with limited access to a computer.
